# Independent Case Submission

External proof is accepted only when it can be checked without exposing private
client data.

Submit a case with:

1. Written permission to publish the domain or an anonymized alternative.
2. A dated before snapshot and the exact intervention list.
3. A dated after snapshot with the same measurement method and window.
4. Source labels for GSC, Yandex Webmaster, CRM, server logs, CrUX, or manual
   observations.
5. Negative results and material confounders, if any.

The project will label cases as `independent`, `maintainer-owned`, or
`synthetic`. It will not turn an unverified testimonial into a performance
claim.
