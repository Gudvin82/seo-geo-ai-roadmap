# v6.9.1 Release Summary

`v6.9.1` adds a growth-ops layer on top of `v6.9.0`.

What changed:

- conversion ops are now a first-class repo and app surface
- content architecture and programmatic SEO planning are now explicit
- customer-research and comparison work has a dedicated operator pack
- launch packaging is safer and easier to reuse in public announcements

New scripts:

- `scripts/conversion_ops_pack.py`
- `scripts/content_growth_ops.py`
- `scripts/customer_research_pack.py`
- `scripts/launch_ops_pack.py`

New app settings centers:

- `conversion-ops-center`
- `content-growth-center`
- `research-ops-center`
- `launch-ops-center`
