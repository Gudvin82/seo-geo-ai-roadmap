# v6.9.3 Release Summary

`v6.9.3` is the current public release state of the repository.

It does three things:

- preserves the growth-ops layer introduced in `v6.9.1`
- carries forward the CI formatting fix from `v6.9.2`
- reduces GitHub Actions noise by limiting core push workflows to `main`

This release is mostly about release hygiene and operational clarity:

- active app and contract markers now match the public release
- frontend release badges now point at `v6.9.3`
- script defaults for launch-oriented helpers now point at `v6.9.3`
- current docs now reference `v6.9.3` as the live state
