# Сводка patch-релиза v6.15.1

`v6.15.1` — patch надежности для релиза v6.15.0 с DataForSEO и project-scoped
MCP. Новых интеграционных возможностей и изменений схемы БД или integration
contract в нем нет.

## Исправления

- Исправлен относительный импорт общей версии приложения, из-за которого
  корневые script-тесты не могли импортировать discoverability checker в CI.
- Smoke-тесты API теперь ожидают безопасный отказ платного DataForSEO sync,
  если отсутствуют credentials или явное разрешение оператора.
- Удалены ожидания фиктивных положительных метрик keyword/competitor при
  отсутствии данных от провайдера.
- Сохранены consent, budget guard, cache и MCP-поведение, добавленные в v6.15.0.

## Проверки

Release candidate должен пройти корневые и backend pytest-наборы, проверки
Ruff, release hygiene, сборку документации и все обязательные GitHub Actions.
Тег считается успешно опубликованным только после прохождения этих проверок.
