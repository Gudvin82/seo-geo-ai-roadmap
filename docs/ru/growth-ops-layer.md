# Growth Ops Layer

`v6.9.1` добавляет практический growth-layer поверх audit и proof foundation.

Этот слой нужен, чтобы findings превращались в реальную работу оператора:

- conversion ops для money pages и lead-flow
- content architecture ops для page systems и schema coverage
- customer-research packs для messaging и comparison surfaces
- launch ops для честных public posts, release notes и showcase-routing

Основные скрипты:

- `scripts/conversion_ops_pack.py`
- `scripts/content_growth_ops.py`
- `scripts/customer_research_pack.py`
- `scripts/launch_ops_pack.py`

Основные app surfaces:

- `conversion-ops-center`
- `content-growth-center`
- `research-ops-center`
- `launch-ops-center`

Operator rule:

- не останавливаться на диагнозе
- каждый серьезный finding доводить до страницы, owner, proof-input и
  launch-safe explanation
