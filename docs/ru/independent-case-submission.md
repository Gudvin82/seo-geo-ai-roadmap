# Подача независимого кейса

Внешний proof принимается только тогда, когда его можно проверить, не раскрывая
приватные данные клиента.

Для кейса нужны:

1. Письменное разрешение на публикацию домена или анонимизированная альтернатива.
2. Датированный snapshot до работ и точный список вмешательств.
3. Датированный snapshot после работ с тем же способом измерения и окном.
4. Метки источников: GSC, Яндекс Вебмастер, CRM, server logs, CrUX или ручные
   наблюдения.
5. Отрицательные результаты и существенные внешние факторы, если они были.

Проект маркирует кейс как `independent`, `maintainer-owned` или `synthetic`.
Непроверяемый отзыв не превращается в performance claim.
