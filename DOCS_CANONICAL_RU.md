# Каноническая Карта Документации

Используйте эту карту до создания нового подробного документа.

| Тема | Канонический документ | Исторический материал |
| --- | --- | --- |
| Границы продукта | `PUBLIC_PRODUCT_READINESS_RU.md` | versioned release notes |
| Методология | `METHODOLOGY_RU.md` | профильные playbook в `docs/en` и `docs/ru` |
| Scoring | `SCORING_EXPLAINED_RU.md` | benchmark и case artifacts |
| Калибровка scoring | `docs/ru/scoring-calibration.md` | consented calibration datasets |
| Деплой | `DEPLOYMENT_RU.md` | platform-specific walkthroughs |
| Зрелость интеграций | generated capability matrix | release-era integration notes |
| Evidence | `REAL_CASES_RU.md` | proof packs и submitted cases |

Versioned-документы объясняют изменение в конкретный момент времени; это не
главный onboarding-путь.
